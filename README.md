# 个人理财台账（licai-ledger）

净值型银行理财的记账与收益跟踪工具。纯静态 PWA：没有第三方服务器，也没有托管你数据的后端 —— 数据只存在两处，**你这台设备的本地存储**和**你自己的 GitHub 私有仓库**。

在线使用：<https://glorywork.github.io/licai-ledger/>（换成你的 Pages 地址即可）

## 它做什么

- 记录每只理财产品的买入/赎回与净值，算出持有收益、年化、贡献占比
- 披露信息（锁定期、开放规则、赎回费档、资产配置、投资范围）按产品留档，缺哪一项就直说缺哪一项
- 节假日与休市日历（按国务院办公厅公告配置），到期提醒按交易日推算
- 多设备同步靠 GitHub：任何一台设备改动后推送到你的私有仓，另一台设备拉回来
- 可安装为桌面/手机应用（PWA），离线可读已有数据

## 数据与密钥的边界

| 东西 | 放在哪 |
| --- | --- |
| 账本数据（产品、交易、净值） | 本机 localStorage + 你的私有仓 `licai-data.json` |
| 访问令牌（GitHub PAT） | 只在内存或 Android Keystore，**绝不写进 localStorage**，不回显、不写日志 |
| 模型 API Key、第三方数据源凭证 | 同上：原生加密槽位或内存态 |

几条贯穿全项目的口径：

- **空值分两种**：`null` 是「不知道」，`0` 是「知道且为零」——把不知道写成 0 会算出假的零收益
- **手工值优先**：机器回填只补空白，绝不覆盖你手工录过的项
- **诚实降级**：取不到就说取不到。没出处就不入账，只记一条缺口
- **结论文本里不写钱**：提醒与摘要只说事实与依据，金额留在表格里

## 自己托管一份

1. Fork 本仓库，把 Pages 的源分支设为 `main`（仓库根目录就是站点根，无需构建步骤）
2. 在同一个账号下建一个**私有仓库**，里面放一份 `licai-data.json`（结构见私有仓的 `schema/licai-data.schema.json`；首次使用可以先不建 —— 设置页里填好 owner / repo / 分支后，连接检查会当场告诉你「数据文件尚不存在，首次推送会自动创建」，并且会警告仓库是不是公开的）
3. 建一个 Fine-grained PAT：对那个私有仓给 **Contents: Read and write**；要手动触发云端自动抓取还得加 **Actions: read and write**。设置页里填 owner / repo / 分支 / 令牌即可
4. 想要「自动抓净值/自动更新披露规则」需要私有侧的抓取流水线（本仓库只含网页与 PWA 外壳，抓取器与自动化不在这里）

## 开发

零构建步骤，纯 ES module。改动必过的本地门禁：

```bash
npm run check   # 版本与资源清单一致 → 语法 → 交易日历 → tsc --noEmit → node --test
```

版本不可变：已经发出去的字节不改。每次改动 = 新的 `APP_VER`（`app.js`）+ 新的 `sw.js` 缓存名 + 一次新构建；老版本的产物永远保持原样，出问题能逐字节比对。
